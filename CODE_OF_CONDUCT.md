# Code of conduct

Treat contributors respectfully. Welcome different backgrounds and experience levels. Critique ideas and code constructively. Harassment, discrimination, threats, sexualized conduct, doxxing and publication of confidential or personal data are unacceptable.

Maintainers may edit/remove harmful content, restrict participation or ban accounts according to severity and recurrence. Apply rules consistently and explain decisions without exposing private information. Conflicted maintainers recuse themselves where another maintainer is available.

To report a conduct issue, contact a maintainer through a private GitHub channel if available. Until a private contact is published, request a confidential contact without posting sensitive details. A formal independent appeals process remains a governance item as the maintainer group grows.
