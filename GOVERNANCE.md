# Governance

The project is independent and vendor-neutral. It requires no service operated by maintainers. Each deployment controls infrastructure, identity, models, data and policies.

Initially the repository owner acts as bootstrap maintainer; additional maintainers are nominated publicly based on sustained contributions and review quality. Decisions and rationale are recorded in issues/ADRs. Seek consensus; if blocked, bootstrap maintainer decides and records conflicts of interest. Companies have no special voting rights through sponsorship. As maintainership expands, adopt a documented multi-maintainer voting and succession process.

Protocol changes require a public proposal, compatibility fixtures and review from mobile/backend implementers. Breaking changes receive new versions; draft status must remain visible. Releases need passing CI, source/dependency review, documented security gaps and validation status. No commercial or regulatory endorsement is implied.
