# Open Pharma Meeting Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline execution. Track each task with its tests and actual validation outcome.

**Goal:** Implement the native local-first iPad milestone and publishable interoperability foundations.

**Architecture:** Six native Swift modules composed by a SwiftUI iPad app. Versioned JSON Schema and OpenAPI provide Android/backend interoperability without shared native implementations.

**Tech Stack:** Swift, SwiftUI, AVFoundation, Apple Speech, XCTest, JSON Schema 2020-12, OpenAPI 3.1.

**Spec:** `docs/superpowers/specs/2026-11-07-platform-design.md`

## Global constraints

- iPad 9/A13, iPad 10/A14, iPadOS 16+; no Apple Intelligence.
- No maintainer service, remote speech fallback, telemetry or production upload in milestone 1.
- Original implementation; exclude unlicensed starter source and archive from publication.
- Private defaults and independent audio/transcript/report permissions.
- Native Android roadmap; public language-independent protocol.

## Review focus

- Termination during capture: finalized chunks survive, unfinished files are clearly marked.
- Speech timeout/cancellation: operation ends once, audio and prior transcript survive.
- Unsupported language in airplane mode: fail closed with actionable status.
- Invalid imports and unknown fields: reject unsafe input, preserve compatible extensions.
- Locked-device/low-space interruption: visible recoverable state, no false success.
